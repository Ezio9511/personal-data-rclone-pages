Personal Data rclone

Personal Data rclone is a private, personal-use OAuth application used to let rclone on the owner's own computer access the owner's Google Drive.

Its purpose is read-only access to the owner's own Google Drive for a personal data archive. This application is not offered as a public service.

The application does not operate a separate web backend for storing Google Drive data. File access is performed by rclone running on the owner's own computer under the owner's direction.
