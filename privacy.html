Privacy Policy

Personal Data rclone is a private, personal-use OAuth application used only by its owner to access the owner's own Google Drive through rclone.

Data access

The application requests access only for the owner's personal use. Google Drive data is accessed by rclone running on the owner's own computer.

Data storage

This application does not operate a separate server that stores Google Drive file contents. OAuth credentials are handled by the owner's local rclone setup.

Data sharing

Google user data is not sold, rented, or shared with third parties.

Use of data

Data is used only for read-only access to the owner's personal Google Drive archive.
